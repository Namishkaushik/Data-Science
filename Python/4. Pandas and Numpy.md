## 3. NumPy Basics

### Importing NumPy

```python
import numpy as np
```

### Creating Arrays

```python
arr = np.array([1, 2, 3])
```

Common creators:

```python
np.zeros((3,3))
np.ones((2,2))
np.arange(0, 10, 2)
np.linspace(0, 1, 5)
np.eye(3)
```
1️⃣ ***np.zeros((3,3))***

Creates a 3×3 array filled with zeros.

```python
[[0. 0. 0.]
 [0. 0. 0.]
 [0. 0. 0.]]
```

 - Shape: (3, 3)

 - Type: float by default

 - Use: Initializing matrices, placeholders

2️⃣ ***np.ones((2,2))***

Creates a 2×2 array filled with ones.

```python
[[1. 1.]
 [1. 1.]]
```

 - Shape: (2, 2)

 - Type: float

 - Use: Initialization, scaling operations

3️⃣ ***np.arange(0, 10, 2)***

Creates values from 0 to 10 (excluding 10) with step size 2.

```python
[0 2 4 6 8]
```

 - Syntax: np.arange(start, stop, step)

 - Similar to Python range()

 - Use: Indexing, loops replacement, numeric sequences

 - ⚠ Stop value is not included

4️⃣ ***np.linspace(0, 1, 5)***

Creates 5 evenly spaced numbers between 0 and 1 (inclusive).

```python
[0.   0.25 0.5  0.75 1. ]
```

 - Syntax: np.linspace(start, stop, number_of_values)

 - Includes both start & end

 - Use: Mathematical plots, scientific computing

5️⃣ ***np.eye(3)***

Creates a 3×3 identity matrix.

```python
[[1. 0. 0.]
 [0. 1. 0.]
 [0. 0. 1.]]
```

 - Diagonal = 1

 - Elsewhere = 0

 - Use: Linear algebra, matrix multiplication

## 10. Random Module

```python
np.random.rand(3,3)
np.random.randn(3,3)
np.random.randint(1, 100, 10)
np.random.choice([1,2,3], size=5)
```
1️⃣ ***np.random.rand(3,3)***

👉 Generates random uniform values between 0 and 1
```python
[[0.12 0.87 0.45]
 [0.66 0.21 0.93]
 [0.04 0.58 0.31]]
```

 - Shape: (3, 3)

 - Distribution: Uniform

 - Range: 0 ≤ value < 1

2️⃣ ***np.random.randn(3,3)***

👉 Generates random values from a standard normal distribution
```python
[[ 0.45 -1.23  0.88]
 [ 1.02  0.11 -0.56]
 [-0.78  0.34  1.56]]
```

 - Mean = 0

 - Standard deviation = 1

 - Distribution: Gaussian / Normal

 - Can be negative

3️⃣ ***np.random.randint(1, 100, 10)***

👉 Generates 10 random integers from 1 to 99
```python
[12 45 3 89 67 21 90 8 54 31]
```

 - Syntax: randint(low, high, size)

 - high is excluded

4️⃣ ***np.random.choice([1,2,3], size=5)***

👉 Randomly selects elements with replacement (default)
```python
[2 1 3 3 1]
```

 - Picks 5 values

 - Values may repeat

 - Without replacement - 
    ```python
    np.random.choice([1,2,3], size=3, replace=False)
    ```

🔑***Comparison table (exam gold)***

| Function	| Distribution	| Output |
|-----------|---------------|--------|
| rand()	| Uniform (0–1)	| Float |
| randn()	| Normal (μ=0, σ=1)	| Float|
| randint()	| Discrete	| Int |
| choice()	| Random selection	| Any |

⚠️ Reproducibility (VERY IMPORTANT)
```python
np.random.seed(42)
```
 - It fixes the starting point of NumPy’s random number generator.

 - After this, every random function will give the same output every time you run the code.

 - So the numbers look random — but they’re predictable.

```python
np.random.rand(3)
# Different output every run
```
With a seed:
```python
np.random.seed(42)
np.random.rand(3)

# You will get the same 3 numbers every time, on any machine (most of the time).
```
***Q. Why the number 42?***

 - 42 is arbitrary

 - Popular because of The Hitchhiker’s Guide to the Galaxy

 - You can use any integer
## 11. Linear Algebra

```python
np.dot(a, b)
np.matmul(a, b)
np.linalg.inv(A)
np.linalg.det(A)
np.linalg.eig(A)
```

Used in ML algorithms.

### Assume matrices
```python
import numpy as np

a = np.array([[1, 2],
              [3, 4]])

b = np.array([[5, 6],
              [7, 8]])
```

1️⃣ ***np.dot(a, b)***

 Dot product / matrix multiplication
```python
np.dot(a, b)
```
Output
```python
[[19 22]
 [43 50]]
```
**Important notes**

 - For 1D arrays → dot product

 - For 2D arrays → matrix multiplication

 - For higher dimensions → behaves differently (exam trap)

2️⃣ ***np.matmul(a, b)***

Strict matrix multiplication
```python
np.matmul(a, b)
```

 - Same result as dot for 2D matrices
 - Does not allow scalar multiplication
 - Recommended for matrix math

Shortcut operator:
```python
a @ b
```

🔑 ***dot vs matmul (VERY IMPORTANT)***

| Feature | dot | matmul |
|---------|-----|--------|
|1D arrays|	Dot product|Dot product|
|2D arrays	|Matrix mult	|Matrix mult|
|Scalars	|Allowed	|❌ Not allowed|
|Higher dims|	Confusing|	Clear & consistent|

👉 Use @ or matmul for ML

3️⃣ ***np.linalg.inv(A)***

Matrix inverse
```python
A = np.array([[1, 2],
              [3, 4]])

np.linalg.inv(A)
```
Ouput 
```python
[[-2.   1. ]
 [ 1.5 -0.5]]
```

⚠ Only works if:

- Matrix is square

- Determinant ≠ 0

4️⃣ ***np.linalg.det(A)***

Determinant
```python
np.linalg.det(A)
```
Output
```python
-2.0
```

Use:

- Check invertibility

- Solve linear systems

- Geometry (area/volume)

5️⃣ ***np.linalg.eig(A)***

Eigenvalues and Eigenvectors
```python
values, vectors = np.linalg.eig(A)
```
Output
```python
values  → [ 5.372, -0.372 ]
vectors → eigenvectors matrix
```

values[i] corresponds to vectors[:, i]

Used in PCA, dimensionality reduction

## 31. Key Definitions & How to Use Them (Concept Clarity Section)

This section explains **what each important concept actually does**, **why it exists**, and **when to use it**.

---

### NumPy Array

**Definition:** A NumPy array is a fixed-size, homogeneous container for numerical data stored in contiguous memory.

**Why it matters:**

* Much faster than Python lists
* Required for ML algorithms

**When to use:**

* Numerical computation
* Matrix operations
* Feeding data into ML models

---

### Vectorization

**Definition:** Performing operations on entire arrays instead of element-by-element loops.

**Example:**

```python
arr * 2
```

**Why it matters:**

* Cleaner code
* 10–100x faster execution

---

### Broadcasting

**Definition:** NumPy’s ability to apply operations between arrays of different shapes.

**Use case:**

```python
arr + 5
```

**Why it matters:**

* Avoids manual looping
* Enables concise math expressions

---

### Boolean Masking

**Definition:** Filtering data using conditions that return True/False.

**Example:**

```python
arr[arr > 10]
```

**Why it matters:**

* Core to data cleaning
* Used everywhere in Pandas filtering

---

### Axis (VERY CONFUSING FOR BEGINNERS)

**Definition:** Axis tells NumPy/Pandas *which direction* to perform operations.

* `axis=0` → column-wise (downwards)
* `axis=1` → row-wise (sideways)

**Example:**

```python
df.sum(axis=0)  # column totals
df.sum(axis=1)  # row totals
```

---

### Pandas Series

**Definition:** A one-dimensional labeled array.

**Why it matters:**

* Represents a single column
* Supports index-based operations

---

### Pandas DataFrame

**Definition:** A two-dimensional labeled data structure (rows + columns).

**Why it matters:**

* Closest to SQL tables / Excel sheets
* Primary object in data analysis

---

### .loc vs .iloc

**Definition:**

* `.loc` → label-based selection
* `.iloc` → position-based selection

**Example:**

```python
df.loc[2]
df.iloc[2]
```

---

### Missing Values (NaN)

**Definition:** Represents absent or undefined data.

**Why it matters:**

* ML models cannot handle NaNs
* Must be cleaned before modeling

**Common strategies:**

* Remove rows
* Fill with mean/median/mode

---

### GroupBy

**Definition:** Split data into groups, apply aggregation, and combine results.

**Use case:**

* Department-wise salary
* Category-wise sales

---

### Merge vs Concat

**Merge:** SQL-style join based on keys

**Concat:** Stack datasets vertically or horizontally

---

### Apply vs Vectorization

**Apply:**

* Flexible
* Slower

**Vectorization:**

* Faster
* Preferred whenever possible

---
